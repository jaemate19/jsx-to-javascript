# JSX to JavaScript Converter

## 🚀 Overview
This project is a JSX-to-JavaScript conversion tool that transforms JSX syntax into browser-compatible JavaScript. It combines traditional parsing techniques with AI-powered processing using the DeepSeek API.

The goal of this project is to demonstrate how JSX is interpreted and converted under the hood, similar to how modern frameworks like React handle JSX.

--- 
 
## ⚙️ Features
- Convert JSX syntax into standard JavaScript
- AI-assisted code transformation using DeepSeek API
- Demonstrates internal workings of JSX transpilation
- Simple and interactive interface

---

## 🧠 How It Works
1. User inputs JSX code
2. The application processes the input
3. A request is sent to the DeepSeek API
4. The API returns converted JavaScript
5. Output is displayed to the user
